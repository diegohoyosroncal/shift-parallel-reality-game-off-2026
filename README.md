# SHIFT: Parallel Reality

Juego de rompecabezas 2D para navegador, creado para **GitHub Game Off 2026** (tema: **SHIFT**).

## Jugar

Abre `index.html` en un navegador moderno. Funciona sin conexión, sin dependencias externas y sin instalar nada.

- **Flechas / WASD:** mover.
- **Espacio / Shift:** cambiar entre Lúmina y Umbra.
- **R:** reiniciar nivel.
- **Móvil:** controles táctiles; tocar el tablero cambia de mundo y deslizarlo mueve una casilla.
- **Objetivo:** recoger los núcleos de ambos mundos y llegar al portal.

Contiene cuatro niveles. La solución de cada uno exige cambiar de dimensión.

## Verificación reproducible

`node --test tests/test_release.cjs`

## Participación

Se necesita el repositorio público y la entrega del juego en itch.io; el repositorio por sí solo no inscribe el juego. Fecha límite: 1 de diciembre de 2026, 13:37 PST.
